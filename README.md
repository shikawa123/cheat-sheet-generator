# Cheat Sheet Generator

An AI-agent skill that turns a folder of lecture-note PDFs into a **dense, print-perfect
A4 exam cheat sheet** — formulas typeset with KaTeX, every parameter explained, and a
closed-loop print-tuning pipeline that guarantees the printed output fits the page
exactly with no clipped edges and (almost) no wasted whitespace.

## What the user provides

Only two things:

1. **Lecture notes** — a folder of PDFs (one per lecture/topic).
2. **Layout** — how many pages, and how many cells per page
   (default: 1 page A4 landscape, 5 × 2 grid = 10 cells, one lecture per cell).

Everything else — content extraction, formula transcription, worked examples,
decision blocks, layout, and print fitting — is generated by the agent following
[`SKILL.md`](SKILL.md).

## Highlights of the method

- **Print-exact pipeline**: HTML + offline KaTeX → headless-Chrome print-to-PDF at exact
  page size, then the *printed PDF itself* is measured (text-span bounding boxes) to
  rebalance every cell's font size / line height until all cells fill to ~1 mm.
- **Chrome quirk workarounds** built in: hairline borders via `scaleY` transforms,
  `--virtual-time-budget` for font loading, `--no-pdf-header-footer`.
- **Readable-at-3.5 pt density**: fraction bars and section rules rendered as true
  hairlines, formulas flush left with parameter notes filling the right side,
  `\sum\nolimits` inside fractions to halve height.
- **Optional colour-coded keyword system** (pastel highlighter bands, eye-friendly):
  yellow = definitions · green = decisions · orange = thresholds · red = test decisions ·
  blue = method names · purple = procedures. Same colour = same kind of answer.
- **Optional per-formula purpose tags**: a short "what is this for" note in a distinct
  colour before each formula's parameter explanation.

## Repository layout

```
SKILL.md              agent-facing workflow (the actual skill)
scripts/
  config.py           page geometry: size, padding, columns, rows, pages, font lock
  content.py          the sheet's content in a small item DSL (one block per cell)
  purpose.py          optional per-formula purpose tags
  markers.py          optional colour-coding (hand pairs + auto keyword list)
  extract.py          lecture-PDF text/image extraction helper
  build.py            content -> HTML (KaTeX) -> PDF via headless Chrome
  tune.py             closed-loop per-cell font/line-height tuning (measures the PDF)
  finalize.py         per-cell line-height bisection (largest spacing that still fits)
  lock35.py           uniform font-size lock mode
```

## Quick start

```bash
npm install katex          # provides katex/package/dist used by build.py
pip install pymupdf
python scripts/extract.py "path/to/lecture-notes" > dump.txt
#   ... agent writes scripts/content.py from the extraction ...
python scripts/build.py && python scripts/tune.py && python scripts/finalize.py
```

Print at **100 % scale**, colour on, background graphics enabled.
